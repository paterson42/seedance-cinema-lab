# Brand assets

The booth video screen (`/screen/trailer`) shows a logo in its top-left corner when one of these
files exists. Drop the official asset in and reload the screen — nothing else needs changing.

- `tiktok-logo.svg` (preferred), or
- `tiktok-logo.png` (transparent background, at least 400 px wide)

Use the official file from the brand's own asset kit; a light/white version reads best on video.
If neither file exists the slot stays empty.
